Recherche avancée

Comment fonctionne la tolérance ?

  • Mode strict : Par défaut, seules les recettes contenant tous les tags sélectionnés sont affichées.
  • Tolérance manquants : Autorise un certain nombre de tags manquants. Exemple : avec 3 tags et une tolérance de 2, les recettes ayant au moins 1 tag seront affichées.
  • Tolérance infinie : Toutes les recettes restent visibles, classées par nombre de tags correspondants (du plus au moins pertinent).
